# ShinyDex 1.1.1

## Release description
Check **Skip Version** before choosing **Later** to stop startup update prompts for that exact release. When a different newer release is available, the update button shows **Update Available**. Skipped versions remain available for manual installation; uncheck Skip Version and choose Later to restore prompts.

Version-2 collections and the desktop profile remain unchanged.

Validation: six desktop tests, controlled Electron updater interaction checks, visual review, Windows x64 NSIS build, and packaged runtime smoke passed. Actual NSIS installation and public update/restart cycles remain untested.

Download **ShinyDex.exe** for Windows x64. The installer is unsigned. **ShinyDex.exe.sha256** contains its SHA-256 checksum; latest.yml and the blockmap support automatic updates.
