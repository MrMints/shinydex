# ShinyDex 1.3.0

## Release description

Pokédex descriptions now appear above hunting methods when you select a Pokémon.
Choose a game to read its description and see that game's recorded hunting methods,
or enable **Show all hunting games**. Your game choice is remembered while the app
is open. Form-specific descriptions retain their labels and reference links.

The offline dataset contains 18,838 English descriptions for all 1,025 catalog
species across 41 games with recorded text, including 1,227 form-labeled entries.
Missing descriptions and hunting records are shown separately. Source collection
does not establish complete localization, spin-off or cartridge coverage, and a
missing record is not proof of a shiny lock.

Version-2 collections, ownership keys, HOME positions and desktop profile remain
compatible. No new hunting eligibility claims are introduced. The exhaustive
hunting audit remains incomplete.

Validation: Windows x64 NSIS build, isolated packaged Electron smoke checks,
browser game switching, responsive screenshot review, desktop storage/updater
regressions, project verifiers, package/source matching and installer manifest
SHA-512 verification. Real NSIS installation/update/restart cycles remain unverified.
