# ShinyDex 1.2.0

## Release description

ShinyDex 1.2.0 improves the Pokédex workspace and form browsing.

- Hunting methods appear after selecting a Pokémon. On wide windows, Pokémon data appears on the left, hunting information in the middle, and the list on the right, with smooth transitions and a close control.
- The workspace uses available window width and height, with compact spacing at 720p and additional visible content at higher resolutions and ultrawide sizes.
- Form arrows beside Pokémon names expand galleries with labeled form images and separate ownership indicators. Gender unspecified is removed from gallery choices; older saved captures remain preserved and can still be assigned to a concrete form.
- Type badges have larger bold text and stronger colors. The hunting table header stays flush with the scrolling panel edge, with spacing below the game filter.

Existing version-2 desktop collections and profile identity are preserved. The exhaustive hunting audit remains incomplete. This release was checked with isolated profiles; real NSIS update/restart cycles and every physical monitor/DPI combination remain unverified.
